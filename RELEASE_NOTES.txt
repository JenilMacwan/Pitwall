PitWall v1.2.2 Release Notes 🏎️🏁

This major update introduces Cloud Authentication, Google OAuth, custom Password Security Spectrum validation, Cloud Firestore synchronization, a redesigned Paddock User Profile, interactive Favorite Constructor & Driver selection, and Navigation Drawer improvements.

🚀 More UI and performance updates coming soon!

--------------------------------------------------------------------------------

🔐 Cloud Authentication & Security Spectrum

- Firebase Auth & Google OAuth: Full support for Email/Password sign-in, account registration, password resets, and Google Sign-In via Android Credential Manager API.
- Password Security Spectrum: Interactive real-time password strength analyzer evaluating 5 security criteria (8+ Chars, A-Z, a-z, 0-9, and Special Characters) with dynamic color spectrum bars and indicator chips.
- Targeted Field Highlighting & Telemetry Snackbars: Auth errors highlight specific input fields with F1 Red borders while displaying sleek top-anchored telemetry Snackbars.
- Smart First-Launch Onboarding: Automatically detects first-time app installs, directing new users to the sign-in/register experience before landing on Home.

--------------------------------------------------------------------------------

☁️ Cloud Firestore Profile Sync

- Cloud Synchronization: Real-time synchronization of user profiles (`users/{uid}`) across devices via Firebase Cloud Firestore.
- Real-Time Profile Stream: Automatically updates user callsigns, avatar photo URLs, favorite teams, and drivers across sessions.

--------------------------------------------------------------------------------

👤 Redesigned Paddock User Profile

- User Profile Hub: Redesigned profile hero card featuring verified driver badges, account email, avatar halo, and dynamic light/dark theme adaptation.
- System Gallery Photo Picker: Integrated native Android photo picker for updating profile avatar images directly from your device gallery.
- Favorite Constructor & Driver Selection: Interactive dropdown selectors to pick and sync your favorite F1 team (e.g. Scuderia Ferrari HP, Red Bull, McLaren) and racer (e.g. Charles Leclerc, Lewis Hamilton, Max Verstappen).
- Help & Support Shortcuts: Direct integrations for Email Support, WhatsApp Paddock Community, Play Store Reviews, and Socials.
- Modern Telemetry Footer: Added custom telemetry footer featuring the tagline *"Built for the fans with ❤️ in India 🇮🇳"*.

--------------------------------------------------------------------------------

🧭 Navigation Drawer & Layout Enhancements

- Scrollable Drawer Content: Restructured navigation drawer so menu items scroll smoothly while keeping the top header and bottom footer pinned.
- Refined Mode Toggle: Compact, touch-friendly segmented Dark/Light mode toggle switch.

--------------------------------------------------------------------------------

📲 Installation
1. Download `PitWall-v1.2.2.apk`.
2. Open the file on your Android device.
3. Enjoy the Formula 1 season with Live Team Radio, Apex AI, Real-Time Telemetry, and Cloud Sync!
